**Raid Manager** — полнофункциональная fullstack веб-платформа для управления гильдиями, статиками и рейдовыми составами в MMO-играх (в частности, **Black Desert Online**). Приложение помогает рейд-лидерам (РЛ) и офицерам вести учет игроков, контролировать классы и роли, планировать осады и игровые события, отмечать посещаемость и детально анализировать активность состава.

🔗 **Демо:** [raidmanager.netlify.app](https://raidmanager.netlify.app/)

## ✨ Ключевые возможности

### 🔐 Аутентификация и ролевая модель (RBAC)
- **Безопасный доступ:** Регистрация и авторизация на базе **JWT** с хэшированием паролей (**bcryptjs**). Срок действия сессии — 30 дней.
- **Иерархия ролей пользователей:**
  - 👑 **ADMIN (Главный администратор):** Первый зарегистрированный аккаунт автоматически получает права администратора. Имеет доступ к модальному окну управления составом пользователей (назначение офицеров и снятие полномочий).
  - ⭐ **OFFICER (Офицер / РЛ):** Создание, редактирование и удаление профилей игроков и событий, выставление и изменение статусов явки на осадах.
  - 👤 **MEMBER (Участник гильдии):** Безопасный режим просмотра ростера, расписания событий и аналитики без прав на модификацию данных.
- **Двухуровневая защита:** Навигационные гарды в `Vue Router` на клиенте и защитные middleware (`authenticateToken`, `requireOfficer`, `requireAdmin`) на Express-сервере.

### 👥 Управление составом (Ростер игроков)
- **Карточки участников:** Учет никнейма, Discord-тега, класса, игровых ролей и уровня игры (скилла).
- **Разделение по статусам:** Вкладки «Активные», «АФК» и «Бывшие участники».
- **Сортировка:** Удобная сортировка списка по имени, классу, роли и уровню скилла.
- **Классы BDO:** Актуальный перечень классов с разделением на стойки (**Традиция** / **Пробуждение**).
- **Мульти-роли:** Назначение игроку нескольких ролей одновременно (ПЛ, Саппорт, МДД, РДД).
- **Быстрый поиск:** Поиск игрока по никнейму в реальном времени.
- **Защита от случайных действий:** Модальные окна с подтверждением перед удалением игрока.

### 📅 Осады и события
- **Планирование:** Создание и редактирование осад, тренировок и сборов с указанием даты, времени, слотов и описания.
- **Интерактивная отметка явки:** Быстрое переключение статусов для каждого участника:
  - ✅ **Пришёл**
  - ❌ **Пропустил**
  - 🚫 **Не допущен**
- **Прогресс-бар посещаемости:** Динамическая цветовая индикация заполненности слотов и явки на карточке события (зеленый / желтый / оранжевый / серый).
- **Детальный состав события:** Модальное окно со списком активных игроков и быстрой сменой статусов офицерами.

### 📈 Аналитика посещаемости игроков
- **Индивидуальная статистика за месяц:** Общая явка (%), количество посещенных, пропущенных и недопущенных событий.
- **Стрики активности:** Автоматический расчет текущего и рекордного стрика посещений подряд.
- **Визуальная история:** Индикаторы статусов последних 7 событий (✅ / ❌ / 🚫) прямо в карточке игрока.

### 📊 Глобальная статистика рейда (Дашборд)
- **Ключевые KPI-метрики:** Количество активных игроков, проведенных событий за месяц, средний процент явки гильдии, лучший стрик.
- **Круговые диаграммы (Chart.js):**
  - Распределение по классам и стойкам.
  - Распределение по уровню скилла.
  - Баланс ролей в рейде (ПЛ, Саппорт, МДД, РДД).
- **График динамики:** Линейный график посещаемости по событиям за последний месяц.
- **Рейтинги:** Топ-5 самых активных и Топ-5 отстающих игроков по проценту посещаемости.

### 📦 Модуль миграции данных (Legacy Migration)
- Автоматическое обнаружение старых данных, сохраненных в `localStorage` браузера (из предыдущих версий приложения).
- Миграционный баннер позволяет в один клик перенести всех участников, события и историю явки в базу данных на сервере.

### 🎨 Премиальный Glassmorphism UI
- Стильный интерфейс с эффектом матового стекла (**Glassmorphism**).
- Темная тема, плавные микро-анимации, неоновые акценты и адаптивная компоновка.

## 🔌 Описание REST API

Все маршруты API имеют префикс `/api`.

### 🛡 Аутентификация (`/api/auth`)
| Метод | Эндпоинт | Доступ | Описание |
|---|---|---|---|
| `POST` | `/api/auth/register` | Публичный | Регистрация (первый пользователь становится `ADMIN`, последующие — `MEMBER`) |
| `POST` | `/api/auth/login` | Публичный | Вход по логину/email и паролю, выдача JWT токена |
| `GET` | `/api/auth/me` | Авторизованный | Получение данных текущего пользователя |
| `GET` | `/api/auth/users` | Только `ADMIN` | Получение списка всех пользователей |
| `PATCH` | `/api/auth/users/:id/role` | Только `ADMIN` | Изменение роли пользователя (`MEMBER` ⇄ `OFFICER`) |

### 👥 Участники рейда (`/api/players`)
| Метод | Эндпоинт | Доступ | Описание |
|---|---|---|---|
| `GET` | `/api/players` | Авторизованный | Получение списка всех игроков рейда |
| `POST` | `/api/players` | `OFFICER`, `ADMIN` | Добавление нового участника |
| `PUT` | `/api/players/:id` | `OFFICER`, `ADMIN` | Редактирование профиля и статуса игрока |
| `DELETE` | `/api/players/:id` | `OFFICER`, `ADMIN` | Удаление участника из базы |

### 📅 События и посещаемость (`/api/events`)
| Метод | Эндпоинт | Доступ | Описание |
|---|---|---|---|
| `GET` | `/api/events` | Авторизованный | Список всех событий с данными посещаемости |
| `POST` | `/api/events` | `OFFICER`, `ADMIN` | Создание нового события |
| `PUT` | `/api/events/:id` | `OFFICER`, `ADMIN` | Редактирование параметров события |
| `DELETE` | `/api/events/:id` | `OFFICER`, `ADMIN` | Удаление события |
| `PUT` | `/api/events/:id/attendance` | `OFFICER`, `ADMIN` | Установка статуса явки игрока (`present`, `absent`, `rejected`) |

### 💓 Сервис проверки
| Метод | Эндпоинт | Доступ | Описание |
|---|---|---|---|
| `GET` | `/api/health` | Публичный | Проверка работоспособности сервера |
